# Neutral Dive Coach (shared copy)

A standalone copy of Neutral. It works offline once installed.

Install on iPhone: open the link in Safari, tap Share, then Add to Home Screen. Open it once with a signal so it saves itself for offline use.

Your data (weighting, notes, certifications, accident records) stays on your phone only. Use Me > Backup to save a copy.

Emergency numbers: SOS > Call, toggle USA or Ecuador. Add your dive operator and the liveaboard's satellite phone before each trip.
